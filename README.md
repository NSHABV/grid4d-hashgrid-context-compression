# Контекстное кодирование HashGrid Grid4D

**Автор: Шабанов Н.А.** Исследовательский код и материалы НИР/ВКР по постобучающему энтропийному кодированию квантованных параметров поля деформаций Grid4D.

Репозиторий содержит исходники анализа, межуровневых контекстов Mean8, PMF clustering H4 и кодера PREVIOUS8, а также отобранные отчёты и численные результаты. Это исследовательский стенд, а не готовый compressor всей сцены Grid4D.

## Основной результат и ограничения

Для фиксированных **GLOBAL8 symbols пространственной xyz HashGrid** сравниваются:

- **X** — XZ на всех уровнях;
- **I** — поканальная IID-модель на L6–L10, XZ на остальных уровнях;
- **P** — PREVIOUS8 на тех же L6–L10, XZ на остальных уровнях.

На четырёх резервных для PREVIOUS8 сценах дополнительная экономия P относительно оплаченного I составляет **23 390 B**, или **0,4511%** суммы I-файлов. Общий переход X→P экономит **324 800 B**; собственный вклад conditioning составляет **7,2014%** этого выигрыша. Источник: [SIX_SCENE_SUMMARY.csv](research/previous8_reserve_batch_20261108_01/SIX_SCENE_SUMMARY.csv), строки `RESERVE_FOR_PREVIOUS8`; арифметическая проверка — `scripts/check_results.py`.

Это actual scene-specific coding: fitted вероятностные таблицы передаются в файле и оплачены. Декодирование точно восстанавливает квантованные symbols; исходные FP32 weights после квантования losslessly не восстанавливаются. PREVIOUS8 использует порядок хранения, а не пространственное соседство hash slots. Temporal grids, MLP и Gaussian-параметры в этом xyz-архиве не сжимаются. Не заявляются новая общая теория entropy coding, превосходство над CNC/NVCC, ускорение rendering или уменьшение его VRAM.

**Начать чтение:** [научная глава](research/context_coding_research_synthesis_20261108_01/CONTEXT_CODING_CHAPTER.md), [позиция для руководителя](research/context_coding_research_synthesis_20261108_01/RESEARCH_POSITION.md), [карта исследований](research/README.md).

## Быстрый запуск без GPU и datasets

Из корня этого репозитория, Python **3.12**; проверенная локальная версия — **3.12.14**, Windows x86-64:

```bash
python -m venv .venv
```

Активируйте окружение:

```powershell
# PowerShell
.venv\Scripts\Activate.ps1
```

```bash
# Linux/macOS shell (этот пакет локально проверен на Windows)
source .venv/bin/activate
```

После активации:

```bash
python -m pip install -r requirements-public.txt
python -B scripts/check_results.py
python -B scripts/run_public_tests.py
```

Публичный набор содержит **81 синтетическую проверку**, включая свежий независимый процесс декодирования X/I/P, exact symbols/classes, byte-identical повтор, границу reset, повреждённый контейнер, геометрию и PMF transport/clustering. Он не запускает обучение, datasets или повторные full-scene исследования. [Протокол проверки публикационного пакета](docs/PUBLICATION_CHECKS.md).

Для уже имеющегося совместимого G4DPREV1-файла:

```bash
python -B research/frozen_previous8_actual_20261108_01/codec.py artifacts/input.bin artifacts/decoded_NEW
```

Входной `.bin` необходимо предоставить отдельно; выходной каталог должен быть новым. Decoder не нуждается в исходном checkpoint или arrays encoder. [Подробности воспроизведения](docs/REPRODUCIBILITY.md).

## Состав

| Каталог | Назначение |
|---|---|
| `research/experiment_bench/` | Вероятностные модели, кодеры пар, H4 и тесты |
| `research/hashgrid_analysis/` | Индексация, геометрия, coarse-only contexts и анализ |
| `research/grid4d/` | Экспорт/квантование; часть интерфейсов требует отдельно установленного PyTorch |
| `research/*_<run_id>/` | Отобранные результаты и необходимые исходники с сохранённой структурой зависимостей |
| `scripts/`, `tests/` | Проверенный лёгкий публичный запуск |
| `docs/` | Воспроизводимость, происхождение, ограничения и раскрытие помощи ИИ |

Не запускайте общий `unittest discover` как обещание полного воспроизведения: некоторые исторические тесты требуют не включённых scene artifacts. `scripts/run_public_tests.py` явно перечисляет синтетический публичный набор; архивные проверки не отключены и не изменены. Исторические команды генерации отчётов могут требовать полного локального архива.

## Данные и сохранность результатов

Datasets, checkpoints, полные symbol exports, рендеры, установленные окружения и тяжёлые bitstreams не включены. Отчёты — помеченные публичные копии: локальные пути адаптированы, отсутствующие артефакты обозначены явно. Численные результаты не пересчитывались. Старые SHA/PASS внутри отчётов относятся к историческим оригиналам; публичные файлы имеют отдельный манифест. [Данные и артефакты](docs/DATA_AND_ARTIFACTS.md), [область публикации](docs/PUBLICATION_SCOPE.md).

## Использование ИИ-агентов

При подготовке исследовательского стенда и материалов ВКР использовались ИИ-агенты OpenAI Codex: для помощи в написании и анализе кода, подготовке тестов, автоматизации разрешённых вычислений и редактировании документации. Выводы опираются на измерения и воспроизводимые проверки, а не на ответы агента. Автор работы отвечает за постановку задачи, интерпретацию и представление результатов. Не заявляется, что весь код написан вручную или прошёл сплошную независимую человеческую проверку. [Подробное раскрытие](docs/AI_ASSISTANCE.md).
