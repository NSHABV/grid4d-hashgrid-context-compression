# G4DPREV1 spatial measurement format
12-byte <8sI prefix: magic G4DPREV1 + canonical JSON byte length. JSON: fixed version1 contract, complete original GLOBAL8 metadata, mode X/I/P,16 descriptors. Descriptor specifies level, codec, rows, model_bytes, payload_bytes list, symbol SHA256. Following sections, in level order: model envelope (empty for X), then one XZ or two range channel streams. Final32B SHA256 of all preceding bytes. No padding.
All XZ payloads copied from sealed XZ6 slot-major. I/P replace exactly L6..10. Two continuous range streams per level, channel0 then channel1. PREVIOUS8 resets context every4096 slots, not stream state. Start row0/9; subsequent row=channel*9+1+searchsorted(edges, previous, right). IID rows0/1. All frozen model bytes transmitted, no CDF duplication; CDF24=CDF16*256 using existing Categorical(perfect=True). Container stream ordering overrides historical descriptive envelope code_order, with identical context/masses/reset meaning. No old decoder semantics changed.
Bounded parse, strict known contract, exact level/shape/codec routing, model validation, SHA256, output hashes and canonical range re-encoding reject malformed streams. Decoder only reads supplied archive after public module import; Python file-open auditing is not an OS sandbox for arbitrary native code.
Metadata/framing = prefix+JSON+final digest. Model bytes and range/XZ payloads separately counted. New X wrapper difference vs old XZ is entirely metadata/framing. Quantization/dequantization remains original GLOBAL8, not lossless FP32 checkpoint reconstruction.
