# Область публичной копии

Подготовлена 14 ноября 2026 года как отдельный набор для GitHub. Исследовательский рабочий каталог не превращён в Git-репозиторий, ничего не отправлено на внешний сервер.

Сохранены основная структура исследовательских модулей, необходимые PREVIOUS8 dependencies, selected final reports, компактные таблицы и проверки. Исторические документы преобразованы только для публикации: удалены идентификаторы локальных путей, исправлены ссылки на включённые файлы, ссылки на исключённые заменены пояснениями. Числа и выводы не подменены.

`SOURCE_PROVENANCE.json` связывает копии с оригиналами по SHA256; дополнительные включённые материалы перечислены в `SOURCE_PROVENANCE_ADDENDUM.json`. Значение `source_sha256` относится к оригиналу, `public_sha256` — к подготовленной копии. Исторические JSON с SHA/PASS имеют исторический смысл и не обязаны совпадать с адаптированным документом. Актуальная публикационная проверка хранится отдельно.

Не включены большие массивы и массовый архив checkpoints/renderings, окружения, внешние репозитории, служебные prompts/continuation, приватные настройки и скачанные статьи. Полные historical scene regression tests не объявляются выполненными из этого сокращённого набора.

Результат предназначен для публикации кода и научных доказательств с явно указанными ограничениями доступности артефактов. Воспроизведение всей цепочки обучения и измерений с нуля не обещается одной командой. Разделы quantization сохранены отдельно от lossless entropy coding; проценты разных объектов не складываются.
