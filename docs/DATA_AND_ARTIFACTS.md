# Данные и исследовательские артефакты

## Не включено в Git

Datasets, checkpoints, frozen full-symbol exports, все scene `.bin`, рендеры, видео, установленные Python/CUDA зависимости, временные файлы, исходники чужих репозиториев и полная история служебных запусков остаются вне этой публикационной копии. Ничего не удалено из исследовательского архива автора.

Исходная модель: [официальный Grid4D](https://github.com/JiaweiXu8/Grid4D), закреплённый исследовательский commit `3ab7b74482910d22fba7d51ac60c8cae1fe24bf1` — источник: [baseline report](../research/BASELINE_GRID4D.md), раздел A. Получение D-NeRF и условия использования следует проверять по ссылкам авторов модели/dataset; файлы dataset не переопубликованы здесь.

## Что доступно без тяжёлых данных

- Исходники моделей, геометрии, сериализации и decoder.
- Синтетические тесты и проверка arithmetic identities.
- Таблицы measured bytes, timings и уровневых вкладов.
- Отчёты с границами actual/estimated/held-out и отрицательными результатами.
- Сведения об исторических проверках и происхождении выбранных файлов.

Таблицы дают проверяемую арифметическую трассировку, но не заменяют входные scene symbols для новой независимой репликации измерений. Исторические PASS не являются новым испытанием скачавшим репозиторий пользователем.

## Возможный отдельный artifact release

Для полноценной проверки сцены отдельно потребуются: точный `.bin` из FILE_SIZES.csv, SHA256, версия decoder, протокол; для повторного encoder — frozen symbols и исходная metadata, определённые его протоколом. Размещать нужно только файлы, для которых допустимо распространение. URL/DOI и статус доступности должны быть добавлены после фактической загрузки, а не заранее выданы за существующие.

Большие архивы подходят для отдельного artifact deposit или GitHub Releases/LFS. В настоящем пакете нет выдуманных ссылок на отсутствующий release. [Каталог исключённых исторических ссылок](EXCLUDED_REFERENCES.json) перечисляет материалы, на которые ссылались оригинальные документы; он не является каталогом доступных скачиваний.
