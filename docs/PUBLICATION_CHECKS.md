# Проверка публикационного пакета

Дата: 14 ноября 2026 года. Это проверка упаковки и воспроизводимости синтетической части, не новое исследование эффективности сжатия.

В отдельном Python-окружении, без исходных `.tools` в пути импорта и без Grid4D/PyTorch, выполнены:

- `python -B scripts/run_public_tests.py`: **81 тест, PASS**.
- `python -B scripts/check_results.py`: **PASS**, суммы reserve 23 390 B и 324 800 B совпали с опубликованными таблицами.

В частности, X/I/P синтетические контейнеры декодированы в свежих процессах; symbols и context IDs совпали, повторные bytes идентичны, чтение данных decoder ограничено переданным `.bin`. Все проверки относятся к small fixtures, а не к повторному декодированию шести сцен. Тесты существующих моделей не изменялись для получения PASS.

Проверенная среда: Windows x86-64, Python 3.12.14, NumPy 1.26.4, constriction 0.4.2. Текст тестового вывода: `PUBLIC_TESTS.log.txt`. Сводная статическая проверка и отдельный перечень файлов: `PUBLICATION_VALIDATION.json` и `PUBLICATION_MANIFEST.json` в корне.

Проверка секретов — поиск известных шаблонов и локальных путей в отобранных текстовых файлах, а не гарантия отсутствия любой возможной конфиденциальной информации. Старые результаты сверены только для фактически использованных источников; новый полный preservation audit всего рабочего диска не заявляется.

GitHub Actions может повторить публичные тесты после публикации; удалённый workflow на момент подготовки не запускался. Новых тренировок, GPU-запусков, scene PMF fits, compression benchmarks или изменения frozen symbols не было.
