# Уровни воспроизводимости

## 1. Проверка опубликованных таблиц

`python -B scripts/check_results.py` использует только сохранённые CSV. Проверяет X−P=(X−I)+(I−P) по шести сценам, контрольные суммы reserve и 20 уровневых вкладов. Это перерасчёт готовых чисел, не новые measurements.

## 2. Синтетическая проверка кодеков

Установите `requirements-public.txt` в новое окружение Python 3.12 и выполните `python -B scripts/run_public_tests.py` из корня. Не нужны GPU, PyTorch, Grid4D checkout, datasets, checkpoints или служебные `.tools` исходного компьютера.

Проверяется 81 тест. Публичная PREVIOUS8 fixture создаёт небольшие синтетические таблицы и заданные целочисленные PMF исключительно для проверки программного контракта. Она не является новой моделью исследования и не используется для выводов о compression ratio. Проверяются X/I/P, граница контекстного блока, оба канала, независимый decoder process, exact symbols/context IDs, повторяемость файла и повреждения контейнера.

Отдельно запускаются существующие синтетические tests геометрии, PMF serialization и H4 optimizer. Исторический полный H4 integration suite дополнительно требует sealed H3 scene bundles; он в публичный CPU-маршрут не включён. Проверки не удалены и не объявлены PASS без выполнения.

Точная проверенная платформа подготовки пакета: Windows x86-64, Python 3.12.14, NumPy 1.26.4, constriction 0.4.2. Другие платформы не объявляются автоматически эквивалентными по классам контекста. NumPy/constriction закреплены; не обновляйте их массово перед проверкой совместимости.

## 3. Независимое декодирование настоящего архива

Предоставьте готовый G4DPREV1 `.bin` и выполните команду из корневого README. Decoder получает только файл и публичный код/зависимости; metadata, PMF и quantizer входят в контейнер. Строгий decoder также повторно кодирует восстановленные range payload для проверки каноничности. Его время не следует выдавать за pure decode latency.

Реальные scene archives не включены в этот Git-пакет. Исторические их размеры и SHA256 доступны в таблицах результатов. Для такого запуска необходимо отдельно получить соответствующий архив; публичной ссылки на загрузку пока не назначено. Заменять отсутствующий файл синтетической fixture и объявлять результат репликацией сцены нельзя.

## 4. Полное повторение обучения и исследования

Требует официального Grid4D, D-NeRF, checkpoints/exports либо нового обучения, совместимого CUDA-окружения и полного набора входных артефактов конкретного протокола. Эта публикационная проверка такое повторение не выполняет. Ветви `research/grid4d` и GPU-analysis требуют дополнительных зависимостей; исторический `environment-blackwell.yml` не является универсальным окружением лёгкого decoder.

Не запускайте архивные generators в каталогах опубликованных результатов. Для новых исследований создавайте новый каталог. Датированные пути сохранены для трассировки зависимостей, а не как разрешение перезаписать отчёт.

## Публикационные изменения

В публичных документах заменены локальные пути и ссылки на исключённые файлы, добавлены пояснения об историческом статусе. Математика PMF, quantization, hash/indexing, context definitions и binary serialization не изменялись. Изменения строк путей в source/report generators перечислены в `SOURCE_PROVENANCE.json`; критические кодеки сравниваются с исходниками при подготовке пакета. Новые публикационные скрипты не заменяют их алгоритмы.

Хеши из старых отчётов относятся к оригиналам. Для текущей публичной версии используйте `PUBLICATION_MANIFEST.json` в корне. Манифест не хеширует сам себя и не является подписью третьей стороны.
